## Facet
---

### Um programa de linha de comando que possibilita usar comandos simples para algum objetivo, Ex.:
• !dx roda um dado de x lados;

• !sys exibe informações do sistema.

Entre outros comandos. Esse projeto tem como objetivo disponibilizar o uso de comandos no terminal de uma forma mais simples para iniciantes ou para quem quer mais praticidade
